# iKF V11 Pro（7.1）音频支持

公开版借助 Windows Core Audio 读取播放和录音端点。EQ、环绕和其他已接入效果依赖已安装且匹配的音频驱动及 APO。程序不会加载厂商控制 SDK，也不提供厂商驱动、固件升级或原厂语音文件。系统的音效属性读回不等同于声学验证。

音频页提供两个方向的音量、静音和电平显示；端点可用时可以查看可支持的声道、格式和默认设备。音效设置可保存本地预设并按程序关联。只在有效的目标端点开放控制；恢复记录绑定到实际设备实例，不会视作其他设备的备份。

各接口的实现与验证状态见 [功能接口](feature-api.md)。不要因安装本程序而卸载提供音效的原有驱动。
